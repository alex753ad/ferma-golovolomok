# Публикация на GitHub Pages (бесплатно)

Всё в папке уже готово: git-репозиторий с историей, офлайн-кэш, иконка, манифест. Осталось 5 шагов.

## 1. Аккаунт
Если аккаунта нет — зарегистрируйтесь на https://github.com (бесплатно).

## 2. Создать репозиторий
1. https://github.com/new
2. Repository name: `ferma-golovolomok`
3. Public (для бесплатного Pages нужен публичный репозиторий)
4. Ничего не добавлять (без README, без .gitignore) → **Create repository**

## 3. Загрузить игру
В терминале в папке игры (замените ЛОГИН на свой логин GitHub):
```
node tools/build-sw.mjs
git add -A
git commit -m "Публикация"
git branch -M main
git remote add origin https://github.com/ЛОГИН/ferma-golovolomok.git
git push -u origin main
```
При первом `git push` откроется окно входа в GitHub — войдите.

## 4. Включить Pages
Репозиторий → **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → **Save**.
Через 1–2 минуты появится ссылка.

## 5. Ссылка для планшета
`https://ЛОГИН.github.io/ferma-golovolomok/`

На планшете:
- **iPad (Safari):** открыть ссылку → «Поделиться» → «На экран «Домой»».
- **Android (Chrome):** открыть ссылку → меню ⋮ → «Добавить на главный экран».

Игра откроется на весь экран и дальше будет работать даже без интернета.

## Как обновлять игру потом
```
node tools/build-sw.mjs
git add -A
git commit -m "Обновление"
git push
```
Планшет подхватит новую версию при следующем запуске с интернетом (иногда нужно закрыть и открыть игру дважды).

## Важно
- Прогресс хранится на самом планшете. Перед сменой планшета или очисткой браузера: ⚙️ → «Для родителей» → «Сохранение» → скопировать код.
- Репозиторий публичный: ответы задач можно увидеть в коде. Ребёнку 12 лет вряд ли это нужно, но имейте в виду.
