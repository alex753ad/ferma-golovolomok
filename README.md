# Ферма Головоломок

3D-игра для планшета: ферма + олимпиадные задачи для 5 класса. Статический сайт, работает без сервера и без интернета (после первой загрузки).

## Запуск на компьютере
1. Откройте папку игры в терминале.
2. `python -m http.server 8000`
3. Откройте http://localhost:8000

Двойной клик по index.html не сработает — браузер не грузит модели с диска.

## На планшете в той же Wi-Fi сети (до публикации)
1. `python -m http.server 8000 --bind 0.0.0.0`
2. Узнайте IP компьютера (`ipconfig` → IPv4, например 192.168.1.5).
3. На планшете: http://192.168.1.5:8000 (если не открывается — разрешите Python в брандмауэре Windows).

## Параметры для проверки (дописать к адресу)
- `?open=all` — открыть все зоны · `?day=1` — вечер · `?q=eco` / `?q=high` — качество графики · `?sw=1` — включить офлайн-кэш на localhost

## Как менять игру
| Что | Где |
|---|---|
| Задачи, подсказки, решения, близнецы, задачи дня, загадки сундуков | `data/tasks.js` |
| Сюжет: пролог, главы, интриги, финал, «что будет завтра» | `data/story.js` |
| Имена семьи, время роста, цены, животные, магазин, поручения мамы, камера, качество | `js/config.js` |
| Карта: зоны, дороги, постройки, места персонажей | `data/map.js` |

После правки задач: `node tools/verify-tasks.mjs --md` — проверит все ответы и обновит `docs/ПРОВЕРКА_ЗАДАЧ.md`.
Перед публикацией: `node tools/build-sw.mjs` — обновит офлайн-кэш (иначе на планшете останется старая версия).

Вход в игру — по PIN (один раз на устройстве, хэш в js/config.js). Прогресс, трудности, достижения, лимиты дня, призы за главы, своя задача («Письмо от папы»), код сохранения — в игре: ⚙️ → «Для папы» (свой PIN, хэш там же).

## Устройство кода
- `js/main.js` — запуск, касания, связь частей, главный цикл
- `js/world.js` — мир, свет, смена дня · `js/nav.js` — сетка проходимости и A* · `js/controls.js` — камера и жесты · `js/minimap.js` — карты
- `js/quest.js` — задачи, попытки, звонок папе, близнецы, звёзды · `js/dialog.js` — окна и диалоги
- `js/farm.js` — грядки, техника, животные, рынок · `js/family.js` — мама и бабушка · `js/story.js` — сюжетные сцены
- `js/day.js` — лимит дня, вечер, серия дней · `js/bonus.js` — задача дня, письма папы, сундуки · `js/pets.js` — Сима и питомцы
- `js/collection.js` — коллекция, значки, призы · `js/parent.js` — родительский режим · `js/settings.js` — настройки
- `js/audio.js` — звуки и музыка · `js/tutorial.js` — обучение · `js/save.js` — сохранение и код сохранения
