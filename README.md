# Ферма Головоломок

3D-игра для планшета: ферма + олимпиадные задачи для 5 класса.

## Как запустить на компьютере
1. Откройте папку игры в терминале.
2. Запустите: `python -m http.server 8000`
3. Откройте в браузере: http://localhost:8000

Двойной клик по index.html не сработает — браузер не грузит модели с диска, нужен сервер.

## Как открыть на планшете (в той же Wi-Fi сети)
1. Запустите: `python -m http.server 8000 --bind 0.0.0.0`
2. Узнайте IP компьютера (`ipconfig` → IPv4, например 192.168.1.5).
3. На планшете откройте http://192.168.1.5:8000
   (если не открывается — разрешите Python в брандмауэре Windows).

## Параметры для проверки (добавить к адресу)
- `?open=all` — открыть все зоны
- `?day=1` — вечер (0 — утро)
- `?q=eco` — экономное качество графики

## Где что лежит
- `js/config.js` — настройки (имена семьи, время роста, камера, качество)
- `data/map.js` — карта: зоны, дороги, постройки, места персонажей
- `js/` — код игры, `assets/` — модели и шрифты, `vendor/three` — three.js
